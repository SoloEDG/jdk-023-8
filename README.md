## 对局回放

球一被蓄力发射，右侧「回放」就开始边打边记：每一帧只保存这一帧按下的操作和经过的毫秒数，
另外每两秒保存一份完整台面快照（关键帧）。因此回放既能重现当时的分数和机关，又不会因为
逐帧保存整张台面把本地存储撑满。

- 「进入回放」会先克隆正在打的那一局；回放播放自己的一份台面，暂停、拖动、逐帧都不会推进
  正在打的那一局。退出回放后，球、分数和奖励时间恢复到进入之前。
- 拖动进度条会从最近的 keyframe 恢复后向前补算，最多补两秒，所以往回拖也能立刻看到那一刻。
- 回放使用单独的模拟路径，且提交被关闭：不会写入对战记录、挑战进度或最佳分数。
- 打完的整局会压缩存进 localStorage（十分钟的局约 335 KB）；重开一局会丢弃上一段回放，
  新局不继承它。

主要代码在 `src/features/replay/`，共用的确定性单帧推进在 `src/app/simulation.ts`。
